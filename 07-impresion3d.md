# Impresión 3D

En esta actividad trabajamos con dos modelos diferentes para impresión 3D. El primero fue un camaleón articulado y el segundo fue un tigre diseñado con ayuda de inteligencia artificial. El objetivo fue conocer el proceso de preparación de los modelos y observar los resultados de su impresión.

## 1. Camaleón articulado

Para este proyecto utilizamos un modelo de camaleón articulado

El modelo cuenta con diferentes partes móviles. Es un diseño interesante porque sus articulaciones permiten que algunas partes se muevan después de imprimirlo.

Proceso de trabajo en SolidWorks:

Descargamos el modelo y sus archivos STL.

Importamos el modelo en SolidWorks para observar su estructura y familiarizarnos con sus diferentes partes.

Revisamos cómo se encuentran distribuidas las piezas y cómo funcionan las articulaciones.

Identificamos las partes móviles, especialmente los ojos y la mandíbula.

Preparamos el modelo para su impresión 3D.

Exportamos y utilizamos los archivos correspondientes para realizar la impresión.

Impresión en dos impresoras diferentes

El mismo diseño se imprimió en dos impresoras distintas, una de ellas de la marca Bambu. Esto permitió comparar los resultados y observar las diferencias en el acabado.

Para evaluar las impresiones se pueden considerar aspectos como:

La definición de los detalles.

La calidad de las capas.

El acabado de la superficie.

El funcionamiento de las articulaciones.

## 2. Tigre diseñado con inteligencia artificial

Para el segundo modelo utilizamos inteligencia artificial como apoyo para generar un diseño de un tigre pequeño. La idea era obtener una figura reconocible, con detalles en la cara, las rayas y las patas, que pudiera imprimirse en 3D.

Prompt utilizado:

"Diseña un tigre pequeño en 3D, de estilo caricaturesco pero reconocible, con detalles definidos en la cara, las rayas y las patas. El modelo debe ser compacto, estable y fácil de imprimir en una impresora 3D, sin soportes complicados. Su tamaño final debe ser de máximo 5 × 5 cm. Genera un modelo tridimensional sólido, con una base plana para que pueda mantenerse de pie y con detalles suficientemente gruesos para que no se pierdan durante la impresión."

Proceso de trabajo:

Escribimos el prompt con las características que queríamos para el tigre.

Utilizamos la inteligencia artificial para generar la propuesta del modelo.

Obtuvimos el archivo 3D para poder prepararlo para impresión.

Revisamos el modelo en el programa de laminado (slicer), donde se configura su orientación, tamaño y parámetros de impresión.

Finalmente, preparamos el archivo para imprimirlo y obtener la figura física.

## 3. Conclusión

Esta actividad nos permitió conocer distintas formas de trabajar con modelos 3D. Con el camaleón aprendimos sobre las piezas articuladas y la importancia de revisar la estructura de un modelo antes de imprimirlo. Por otro lado, con el tigre exploramos cómo la inteligencia artificial puede ayudarnos a generar diseños tridimensionales.

También fue interesante comparar la impresión de un mismo modelo en dos impresoras diferentes y observar cómo la configuración y las características de cada máquina pueden influir en el resultado.

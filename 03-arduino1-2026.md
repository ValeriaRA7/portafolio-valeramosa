# ¿Qué es Arduino? 
Arduino es una plataforma de electrónica que utiliza una placa programable para crear diferentes proyectos. La placa tiene un microcontrolador que puede recibir información de sensores y controlar diferentes componentes, como luces, motores, botones, pantallas, etc. Se utiliza mucho para aprender programación y electrónica porque permite hacer que un programa controle objetos físicos.

## ¿Cómo se utiliza? 
Para utilizar Arduino, primero se conecta la placa a una computadora mediante un cable USB. Después, se escribe un programa en el Arduino IDE, que es el programa utilizado para programar la placa. Una vez terminado el código, se carga a Arduino y este empieza a ejecutarlo. Dependiendo de lo que se quiera hacer, se pueden conectar diferentes componentes, como un LED, un botón o un sensor. Por ejemplo, se puede programar Arduino para que cuando un sensor detecte movimiento, encienda una luz.

## Lista de materiales
### Arduino Uno

![Blink1](assets/img/01-publicar/arduino/arduinouno02.jpeg)
Es la placa principal. Es donde se carga el programa y que controla todos los componentes conectados.

### Protoboard (Breadboard)
Foto: 
![Blink1](assets/img/01-publicar/arduino/protoboard02.jpeg)
Es una placa que permite conectar componentes sin tener que soldarlos. Sirve para armar y probar circuitos fácilmente.

### Cable USB tipo A-B
Foto:
![Blink1](assets/img/01-publicar/arduino/cableUSB02.jpeg)
Sirve para conectar una placa Arduino a la computadora y cargarle el programa. El extremo USB-A se conecta a la computadora y el USB-B a la placa, siempre que esta tenga ese tipo de puerto. 

### Cables de conexión para fuente de alimentación
Foto: 
![Blink1](assets/img/01-publicar/arduino/cableexterna02.jpeg)
Estos cables permiten conectar una fuente de alimentación a un circuito para suministrarle energía eléctrica. Se utilizan en prácticas de electrónica para alimentar circuitos y realizar pruebas. Generalmente, el cable rojo corresponde al positivo (+) y el negro al negativo (−).

### Cables Jumper
Foto: 
![Blink1](assets/img/01-publicar/arduino/cablesjumper02.jpeg)
Son cables pequeños que sirven para conectar Arduino con la protoboard y los diferentes componentes.

### LED
Foto:
![Blink1](assets/img/01-publicar/arduino/lucesled02.jpeg)
Es una pequeña luz que Arduino puede encender y apagar mediante programación. Hay LEDs de diferentes colores.

### Resistencias
Foto 220/330:
![Blink1](assets/img/01-publicar/arduino/resistencia22002.jpeg)
Foto 10:
![Blink1](assets/img/01-publicar/arduino/resistencia1002.jpeg)
Las resistencias de 220 Ω o 330 Ω limitan la corriente eléctrica para proteger componentes como los LEDs, mientras que las de 10 kΩ se utilizan comúnmente para estabilizar las señales eléctricas de botones y sensores, evitando lecturas incorrectas.

#### Botón (Push Button)
Foto:
![Blink1](assets/img/01-publicar/arduino/boton02.jpeg)
Permite enviar una señal a Arduino cuando se presiona. Por ejemplo, puedes programarlo para que al presionar el botón se encienda un LED.

### Potenciómetro
Foto:
![Blink1](assets/img/01-publicar/arduino/potenciometro02.jpeg)
Es una resistencia que se puede ajustar manualmente. Se puede utilizar, por ejemplo, para controlar el brillo de un LED o el volumen de un sonido.

### Servomotor
Foto:
![Blink1](assets/img/01-publicar/arduino/servomotor02.jpeg)
Es un motor que puede girar hasta una posición específica. Se utiliza en proyectos de robótica, puertas automáticas, brazos robóticos, etc.

### Display digital de 7 segmentos
Foto: 
![Blink1](assets/img/01-publicar/arduino/display7seg02.jpeg)
Es una pequeña pantalla formada por siete segmentos luminosos que se pueden encender en diferentes combinaciones para mostrar números del 0 al 9. Se utiliza en contadores, relojes, temporizadores y otros proyectos.
